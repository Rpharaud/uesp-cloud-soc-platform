# Engineering Competency Matrix

> **Build Like an Engineer. Think Like an Architect.**

---

## Purpose

The **Engineering Competency Matrix** serves as the authoritative record of technical competencies developed throughout the Security Engineering & Cloud Architecture Residency (SECAR).

Rather than listing technologies or certifications, this document maps engineering competencies to tangible evidence produced during the residency. It provides a structured way to assess growth, identify skill gaps, support interview preparation, and demonstrate professional capability.

This document is intended to serve as the primary source for resume development, portfolio updates, and technical interview preparation.

---

## Competency Levels

| Level | Description                                                                            |
| ----: | -------------------------------------------------------------------------------------- |
| **1** | Awareness – Understands concepts and terminology.                                      |
| **2** | Working Knowledge – Can complete guided implementation tasks.                          |
| **3** | Independent Practitioner – Can independently design and implement solutions.           |
| **4** | Advanced Practitioner – Can optimize, troubleshoot, and mentor others.                 |
| **5** | Technical Leadership – Able to define strategy, architecture, and technical direction. |
