# Security Engineering & Cloud Architecture Residency (SECAR)

> **Build Like an Engineer. Think Like an Architect.**

---

## Purpose

The Security Engineering & Cloud Architecture Residency (SECAR) is a structured engineering residency designed to develop a well-rounded Security Engineer capable of designing, implementing, securing, operating, and defending modern cloud-native environments.

Unlike certification-first learning paths, SECAR emphasizes engineering practice, architectural decision-making, documentation, governance, and portfolio development. Every phase produces tangible engineering artifacts that demonstrate competency and professional growth.

The residency culminates in a production-quality flagship platform, a comprehensive engineering portfolio, and the technical depth expected of a mid-to-senior Security Engineer.

---

## Residency Philosophy

SECAR is built on five guiding principles:

1. **Engineering Before Certifications** – Certifications validate knowledge; projects demonstrate competence.
2. **Documentation Is Engineering** – Good engineers build systems. Great engineers build systems that others can understand.
3. **Architecture Requires Intentional Decisions** – Every significant technical decision should be documented and justified.
4. **Evidence Over Claims** – Every skill should be supported by code, documentation, architecture, or operational artifacts.
5. **Continuous Improvement** – Every sprint should leave the platform and the engineer better than before.

## Graduation

### Capstone Project

Complete and present the UESP Cloud SOC Platform demonstrating end-to-end engineering capability.

---

### Graduation Requirements

* Complete all residency phases
* Complete the flagship platform
* Complete Architecture Decision Records (ADRs)
* Maintain engineering documentation
* Complete planned design reviews
* Achieve target certification milestones
* Build a professional engineering portfolio
* Complete mock technical interviews
* Present the capstone architecture
* Successfully defend engineering decisions

---

### Expected Graduate Profile

A SECAR graduate should be capable of:

* Designing secure cloud-native architectures
* Building infrastructure using Infrastructure as Code
* Engineering detections and monitoring pipelines
* Performing threat hunting and incident response
* Applying security architecture principles
* Communicating technical decisions through documentation
* Leading engineering discussions and design reviews
* Producing portfolio-quality engineering artifacts suitable for senior security engineering roles

---

## Success Metrics

The residency is considered successful when the participant has produced:

* A production-quality flagship platform
* A mature GitHub engineering portfolio
* Comprehensive engineering documentation
* Architecture Decision Records (ADRs)
* Sprint history and design reviews
* Detection engineering artifacts
* Cloud infrastructure modules
* Interview-ready technical stories supported by real engineering evidence

---

## Continuous Evolution

SECAR is intended to evolve over time. New phases, technologies, certifications, and engineering practices may be incorporated as cloud security and modern software engineering continue to mature. Any significant changes to the residency roadmap should be documented through the established architecture governance process.
